# Artist site: frontend
React + Vite + Tailwind CSS + Framer Motion. It needs the backend in `../backend` to run.
See `../GUIDE.md` for the full step-by-step setup.

    npm install
    cp .env.example .env     # set VITE_API_URL
    npm run dev

Pages: `/` home, `/#/videos`, `/#/blog`, `/#/privacy`, `/#/terms`, `/#/admin`
